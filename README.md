# FlashMem（瞬間視）

設定した時間だけ数字を同時に出し、場所を覚えてから、真ん中が示した数字の端末をタップします。

- 表示は 0.1〜1 秒
- 簡単は 1 からの連番。難しいは 0〜99 で、2 桁を含み、重複しない
- コントローラーに数字を出すかは選べる。出していたときはコントローラーをタップする
- 左右2分割は 1 台に数字が 2 つ。出ていた側をタップする
- 全部答え終わると、正解は緑、不正解は赤。結果は正答 x/x
- コントローラを含めて 3〜7 台。配置は周辺視タップと同じ

ローカル確認: `npm install` のあと `npm test`、`npm run dev`。
